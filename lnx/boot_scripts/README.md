# Подготовка скриптов для процесса uboot-загрузки

Данные скрипты используются в работе SPL - *вторичного* загрузчика - Linux UBoot.  
Определяют список загружаемых файлов и манипуляции с ними.

Образ ядра Linux, корневой файловой системы, описания устройст на SoC (uImage, URootfs.image.gz, system.dtb) .

## Сборка
```
$ ./build.sh
```

## Ожидаемый результат
```
xme0724-20/boot.scr.sd
xme0724-20/boot.scr.mmc
xme0724-20/boot.scr.qspi
xme0724-20/boot.scr.tftp
```

*Примечание:* скрипт **xme0724-20/boot.scr.qspi** прошивается в QSPI флэш.
