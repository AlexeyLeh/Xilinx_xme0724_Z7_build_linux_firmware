# Подготовка файла описания устройств, сконфигурированных в XME0724-20 (system.dtb)

## Требования
Ниже упомянуты устройства, которые должны быть внесены в Device Tree.  
При сборке проекта все эти устройства автоматически вносяться скриптом сборки,
т.е. *ручная* правка, в общем случае, не требуется.

## Доработка описания для RTC M41T00
Файл zynq-7000.dtsi - добавить в секцию с i2c блок описания rtc:

```
i2c0: i2c@e0004000 {
        compatible = "cdns,i2c-r1p10";
        status = "disabled";
        clocks = <&clkc 38>;
        interrupt-parent = <&intc>;
        interrupts = <0 25 4>;
        reg = <0xe0004000 0x1000>;
        #address-cells = <1>;
        #size-cells = <0>;
        rtc@68 {
                compatible = "st,m41t00";
                reg = <0x68>;
                interrupt-parent = <&intc>;
                interrupts = <0x9 0x8>;
        };
};
```

## При сборке ядра Linux 
Перед сборкой ядра Linux **выбрать использование модуля DS1307** в конфигурации.
