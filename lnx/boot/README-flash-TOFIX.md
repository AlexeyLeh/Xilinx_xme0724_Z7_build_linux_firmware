# Скрипты прошивки загрузчиков в QSPI флэш

## Требования
- Должно быть установлено приложение Xilinx Designed Tools (Vivado).
- Путь к бинарникам должен быть прописан в переменную окружения PATH.
- Файлы для прошивки ищутся в каталоге *<project>/BOOT/qspi/* и должны быть заранее сформированы.

### Windows - версия

- Путь к бинарникам:

    `set PATH=%PATH%:C:\Xilinx\SDK\2018.3\bin`

    *или воспользоваться штатным оконным способом*
    *Параметры - Система - О Программе - Доп.параметры системы - Переменные среды*

- Скрипт flash.bat
```
flash.bat
program_flash.bat
```
- запуск - `> flash.bat`

### Linux - версия (WSL)

- Путь к бинарникам:

`export PATH=$PATH:$HOME/app/Xilinx/SDK/2018.3/bin`

- Скрипт flash.sh
```
flash.sh
```
- запуск - `$ ./flash.sh`
