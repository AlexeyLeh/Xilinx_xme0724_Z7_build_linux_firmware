# Подготовка linux-файловой системы

(оно-же rootfs initrd initramdisk initramfs)

## Исходники

- Файловая система делается на основе технологии rootfs. \
Подготовка rootfs выполняется единожды и в дальнейшем просто используется для формирования загрузочного комплекта Linux-а.

Подготовка выполняется в каталоге [**creation**](./creation) [README](creation/README.md). \
Результатом подготовки является фархив **creation/rootfs.tar.bz2**, который используется на данном этоапе.

## Сборка
Подготовка образа rootfs для загрузки в linux-е выполняется скриптом сборки - **build.sh**
```
$ ./build.sh
```

# Скрипты сборки

- **build.sh** - основной скрипт, выполняющий последовательно необходимые действия
- **build-rootfs.sh** - скрипт подготовки загрузочного комплекта *rootfs*

### Ожидаемый результат сборки
```
uRootfs.image.gz
```
*Примечание*: **uRootfs.image.gz* это *упакованный* для процедуры UBoot-загрузки файл **rootfs.image.gz**
